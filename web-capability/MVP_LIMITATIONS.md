# MVP 已知限制

- `robots.txt` 已接入抓取链路并复用正文抓取的 URL 防护、DNS 校验、逐跳 IP 固定、重定向次数、超时和响应大小限制。当前策略使用进程内缓存，4xx 按 RFC 视为不可用并允许抓取；5xx、网络失败、解析失败和超过 5 次重定向则 fail-closed。多实例部署前需要外部缓存或明确接受实例级缓存命中率。
- 动态 JavaScript 页面和登录态浏览不在本阶段范围内；服务只对公开页面执行只读 HTTP 抓取。
- Tavily/Brave/Exa 搜索响应只在内存中进行规范化和短期缓存，不由本服务主动持久化搜索正文；这不代表上游供应商零留存。UsageLogger 只输出结构化元数据，不记录原始 query、API Key 或正文。不得把密钥、个人信息、内部源码或客户机密放进搜索查询，敏感业务上线前必须另行确认供应商合同、DPA、查询保留和第三方共享条款。
- 当前 usage 记录默认输出到服务日志，尚未写入 PostgreSQL 或其他长期账本；需要计费、审计和跨实例统计时，应替换为持久化 `UsageLogger` 实现。
- 当前缓存是单进程内存缓存，不跨进程共享；多实例部署前需要外部缓存或明确接受实例级缓存命中率。
- `WEB_CAPABILITY_ALLOW_BENCHMARK_DNS_PROXY=true` 只用于受管开发环境：它仅允许“域名 DNS 答案”为 `198.18.0.0/15` 时使用该代理地址，默认关闭，不能用于生产。IP 字面量及其他非公网地址不会因此放行。
