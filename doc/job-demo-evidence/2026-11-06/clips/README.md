# 讲解成片与两段原始UI录屏

[讲解成片](narrated-demo.webm)为182.12秒、1280×720的中文静态字幕与原片回放。
片头明确标注“讲解成片，内含两段原始真实UI录屏回放”；它不是一段连续真实业务执行，也未新增Robot/模型调用。
恢复HTTP500不能由画面单独证明，须配对原Job、测试断言及XML/JSON回执；未录桌面、其他程序、个人Profile或RPA Chrome窗口。
[成片manifest](narrated-manifest.json)记录时长、编码、文件哈希和首中末抽帧；一次性脚本/HTML仅留在私下evidence/temp，不成为产品页面或框架。
2026-11-06封板时，Independent AI Reviewer已限定接受实际编码的六个抽帧，正文和限制可读；这是AI媒体复核，不是人类业务审批，成片没有音轨。

这是实际运行测试时录下的两个原始WebM片段，合计56.44秒，均为1280×720；没有转码、拼帧或剪成新的流程。
下面两段原片本身不是完整讲解成片；182.12秒成片另列于上方，讲解提纲仍见[展示验收](../../../求职展示验收.md)。

两例均通过真实FastAPI静态UI、原批准接口、生产草稿适配器及RPA模块、真实Robot子进程和Selenium/WebDriver。
模型与来源为synthetic，目标为loopback模拟创作后台，不调用收费模型、不接触真实账号。
视频只录本地合成UI页面，没有录桌面、其他程序、个人Profile或RPA Chrome窗口；Robot过程由配对XML/Job回执证明。

| 短片 | 时长 | 建议讲解 |
|---|---|---|
| [正常、版本编辑与审核](normal-edit-review/raw.webm) | 28.28秒 | 已保存第1版候选，上传合成图片，另存第2版；批准当前版本，再确认保存草稿；刷新后核对原任务结果 |
| [写回异常后的恢复](recovery/raw.webm) | 28.16秒 | 同样审核并启动；Robot成功后在真实SQLite写回边界注入失败，HTTP500；移除故障后刷新，以原Job对账恢复，不重复保存 |

可以配合画面讲：“候选不是批准，编辑和图片另存版本后才审核；执行先有持久关联，结果不明先查询原任务。”
第一段展示的是添加图片并另存版本后审核，未展示“批准后再次编辑使旧批准失效”；后者有独立离线准入测试，不能扩为本段视频覆盖。
浏览器原生确认弹窗可能不出现在页面录屏里；测试操作员接受的真实弹窗文案保留在各manifest中。

每个目录包含原始`raw.webm`、合成UI刷新后截图、去敏manifest及Robot XML摘要。
manifest保留视频时长/分辨率/SHA256、原execution/Job ID、确认文案及读回字段；不复制原始DB、Profile、下载二进制或SDK请求。
核验范围仅为标题、正文、标签文字和图片数量，不证明图片内容、平台原生话题、真实模型质量或真实小红书兼容性。
