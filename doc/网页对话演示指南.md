# Mini Agent 网页对话演示指南

## 启动

默认 Agent 在进程内直连 AGSX 和 Tavily，不需要启动 Gateway 或 Web Capability。
如果 `.env` 中启用了 `MEMORY_ENABLED=true`，先启动独立的 LazyTT Memory 后端，再启动网页 Agent：

```bash
cd /Users/drb/code/TestAgent
UV_CACHE_DIR=/tmp/testagent-uv-cache uv run python scripts/memory_backend.py up
UV_CACHE_DIR=/tmp/testagent-uv-cache uv run uvicorn web_agent.app:app \
  --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。

## 推荐演示顺序

1. 先问普通问题，展示模型对话：

   ```text
   简单介绍你有哪些能力。
   ```

2. 点击“运行 Python”，展示模型自主选择 `run_code`、沙箱执行和销毁。

3. 点击“生成经营简报”，展示 CSV 上传、通用分析和 JSON/SVG/Markdown/PDF/PPTX Artifact。

4. Browser 配置完成后点击“浏览公开网页”，展示正文、截图和不可信内容边界。

每条 Agent 回答下方可以展开“执行轨迹”，看到模型调用、Memory Policy、历史裁剪、
Context Pack、工具执行和脱敏 Context Receipt。

## 页面状态说明

- 模型“已配置”：`.env` 中存在 `OPENAI_API_KEY` 和 `OPENAI_MODEL`。
- AGSX Code“已配置”：存在 `E2B_API_KEY`、`E2B_DOMAIN` 和 `AGSX_TEMPLATE`。
- AGSX Browser“已配置”：Code 配置完整，并存在 `AGSX_BROWSER_TEMPLATE`。
- Tavily Search“已配置”：存在 `TAVILY_API_KEY`。
- LazyTT Memory“已配置”：已启用记忆，且 Memory Service 的地址与认证配置有效。

## 当前边界

- 短期对话保存在服务端 `.local/conversations.sqlite3`，浏览器通过 `conversation_id` 在刷新后恢复；“清空对话”删除当前 Conversation，但不删除长期记忆。
- 默认 `MEMORY_RECALL_POLICY=adaptive`：明确的 Python、纯计算、指定文件/URL 任务跳过召回；历史、偏好、项目连续性问题召回；普通任务暂时默认召回。
- 每轮回答成功后自动从本轮用户原话提取记忆候选；Memory Service 不可用时自动降级为无记忆对话。
- 最近历史按完整 user/assistant 轮次和字符预算选择，不接收浏览器伪造的 history；当前工具调用链不跨轮保存。
- 每次请求新建一个 Agent Loop，工具沙箱仍是“一次调用一个实例”。
- 当前 Code、表格分析、经营简报和 Browser 工具在 Agent 进程内直连 AGSX，搜索直连 Tavily。
- Provider 密钥会进入本地 Agent 进程，但不会返回网页前端、模型提示或工具结果。
- 仅监听 `127.0.0.1`；不要把带有真实模型和沙箱密钥的服务直接开放到公网。
