# Mini Agent 网页对话演示指南

## 启动

终端 1 启动 Gateway：

```bash
cd /Users/drb/code/TestAgent
UV_CACHE_DIR=/tmp/testagent-uv-cache uv run uvicorn sandbox_gateway.factory:app \
  --host 127.0.0.1 --port 8787
```

终端 2 启动网页 Agent：

```bash
cd /Users/drb/code/TestAgent
UV_CACHE_DIR=/tmp/testagent-uv-cache uv run uvicorn web_agent.app:app \
  --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。

## 推荐演示顺序

1. 先问普通问题，展示模型对话：

   ```text
   简单介绍你有哪些能力。
   ```

2. 点击“运行 Python”，展示模型自主选择 `run_code`、沙箱执行和销毁。

3. 点击“生成经营简报”，展示 CSV 上传、通用分析和 JSON/SVG/Markdown/PDF/PPTX Artifact。

4. Browser 配置完成后点击“浏览公开网页”，展示正文、截图和不可信内容边界。

每条 Agent 回答下方可以展开“执行轨迹”，看到模型调用和工具执行步骤。

## 页面状态说明

- 模型“已配置”：`.env` 中存在 `OPENAI_API_KEY` 和 `OPENAI_MODEL`。
- Sandbox Gateway“已配置”：Agent 已配置 Gateway 地址与 Agent API Key。
- 沙箱工具“已配置”：表示调用入口已配置；具体 Provider 能力仍以真实执行结果为准。

## 当前边界

- 支持多轮文本上下文，但不持久化；刷新页面会清空。
- 每次请求新建一个 Agent Loop，工具沙箱仍是“一次调用一个实例”。
- 当前 Code、表格分析、经营简报和 Browser 工具均通过 Sandbox Gateway；Provider 密钥只在 Gateway 进程中使用。
- 仅监听 `127.0.0.1`；不要把带有真实模型和沙箱密钥的服务直接开放到公网。
